# Joy-Con 2 Boat Game

## 作品概要

Joy-Con 2を実際のオールのように前後へ動かし、
ボートを操作するUnreal Engine 5製のゲームです。

一般的なスティック操作ではなく、
Joy-Con 2のセンサー入力を利用することで、
実際にボートを漕ぐような操作感を目指しました。

- vJoy

## 操作方法

- 両方を引く：前進
- 両方を押す：後退
- 左を引く：右旋回
- 右を引く：左旋回

## 主な実装

### ボート操作

左右のJoy-Con 2から取得した入力を判定し、
ボートの前進・後退・旋回へ反映する処理を実装しました。

左右を別々の入力として扱うことで、
実際に左右のオールを漕ぐような操作方法を目指しています。

### Joy-Con 2との入力連携

Joy-Con 2をWindows上で利用するため、
OSSの「Joy2Win」を使用しています。

Joy2Winから取得した入力をvJoyへ渡し、
Unreal Engine 5側でゲーム操作として利用しています。

## Joy2Winの改変について

Joy2Winをそのまま使用するだけではなく、
本作品の操作方法に合わせるため、
マウスセンサー入力に関する処理を一部追加・調整しています。

主な変更内容：

- Joy-Con 2のマウスセンサー入力処理をゲーム操作向けに調整
- 左右のJoy-Con 2の入力を個別に取得
- 入力値をvJoy経由でUnreal Engine 5へ送信
- 取得した入力をボート操作に利用

## 工夫した点

通常のゲームパッド操作ではなく、
Joy-Con 2を実際に前後へ動かす操作をゲーム内のボート移動へ
結び付けることを意識しました。

左右のJoy-Con 2をそれぞれ独立して扱うことで、
両方を動かした場合と片方だけを動かした場合で
異なるボート操作が行えるようにしています。

また、既存のOSSを利用する際には、
必要な処理を調査し、
ゲームの仕様に合わせて変更することにも取り組みました。

## 総括

本制作では、
Joy-Con 2という新しい入力デバイスをUnreal Engine 5と連携させ、
実際の動作をゲーム操作へ変換する仕組みの実装に取り組みました。

また、Joy2Winなどの既存OSSについてソースコードを調査し、
目的に合わせて一部を変更する経験を得ました。

入力取得からゲーム側の処理までをつなげることで、
複数の技術を組み合わせて一つのシステムを構築する経験になりました。
